## 变更类型

- [ ] 🐛 Bug 修复

## 风险评估

### 影响面
- [ ] 仅影响当前模块
- [ ] 影响多个模块（请列出）
- [ ] 影响公共接口/API
- [ ] 涉及数据库变更
- [ ] 涉及配置文件变更

### 风险等级
- [ ] 🔴 高风险（核心逻辑/安全相关，需要2名审查者）
- [ ] 🟡 中风险（功能变更/重构）
- [ ] 💭 低风险（文档/样式/测试补充）

## Checklist

- [ ] 代码已通过本地 lint 检查
- [ ] 代码已通过本地测试
- [ ] 自审已覆盖通用审查清单的相关项
- [ ] 添加了必要的注释（特别是复杂逻辑和 hack）
- [ ] 更新了相关文档（如适用）
- [ ] 无调试代码残留（console.log / println! / print）
- [ ] 无敏感信息泄漏（密钥、密码、Token）
